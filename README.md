## 概要

「Trigger Rummy」は、麻雀のような役作り・鳴き・リーチ・ロン/ツモの駆け引きと、トランプゲームの分かりやすさを組み合わせた、3〜5人対応のオリジナル対戦カードゲームです。

手札10枚から3枚1組の役を3つ作り、残り1枚を得点札として扱います。  
山札または捨て札からカードを引き、不要なカードを1枚捨てながら、同ランク3枚や同スート連番3枚などの役完成を目指します。

CPU対戦とオンライン対戦の両方に対応しており、1人でもCPUを相手にゲームの流れを確認できます。

## ホーム画面の各メニュー

### New Game

新しい対戦ルームを作成、または既存の公開ルームに参加するための画面です。

New Game内には主に以下の導線があります。

- ルームを立ち上げる
- ルームに入る

### More Game

途中離脱した試合のリストが表示されます。  
再開可能な試合がある場合、この画面から復帰できます。

### Settings

SE、BGMなどの各種設定を行う画面です。

### Manual

試合の概要、基本ルール、進め方などを確認できます。  
プレイ画面内の設定メニューからもマニュアルを確認できます。

### Profile

アバターの変更を行う画面です。  
アバター変更は実装済みです。  
アバターボイスの確認機能は今後実装予定です。

## New Game：ルーム作成

「ルームを立ち上げる」では、以下の項目を設定して対戦ルームを作成します。

- ルーム名
- 対戦人数
- 参加内訳
- 試合形式
- 追加ルール
- 公開 / 非公開設定
- 途中参加の許可設定

### 1人で遊ぶ場合

例として5人対戦を1人で遊ぶ場合は、参加内訳を「人間1人 + CPU4体」のように設定します。  
このように人間プレイヤーが自分だけの場合、他の人が参加する必要がないため、ルームは自動的に非公開になります。

### 複数人で遊ぶ場合

複数人プレイの場合は、対象人数とCPUの有無を設定したうえで、ルームを公開にすると、他のプレイヤーが「New Game → ルームに入る」の公開ルーム一覧から参加できるようになります。

現在は、公開ルームに参加する形式を中心に実装しています。  
フレンド機能などを利用した非公開の複数人対戦は今後実装予定です。

### ルーム作成後

ルーム作成後はプレイ画面に遷移します。  
ルールや試合の進め方はManualページに記載しています。  
また、プレイ画面内の設定メニューからもManualを確認できます。

---

## New Game：ルームに入る

公開設定になっているルームが一覧表示されます。  
参加可能なルームを選ぶことで、そのルームに参加できます。

人間プレイヤーのみで人数が揃うまで待つこともできますが、途中参加が許可されている場合は、人数が揃っていない状態でも試合を開始できます。  
その場合、足りない人数分はCPUが一時的に代行プレイします。

## プレイ画面内の設定メニュー

プレイ画面内の設定メニューでは、試合中に必要な操作や情報確認を行えます。

### 退出

試合またはルームから退出します。  
画面上の表示に従って操作できます。

### Manual

試合中にルールや進め方を確認できます。

### 一時離脱

一時離脱では、以下のどちらかを選択できます。

1. 自分の手番になった時点で試合進行を中断させる
2. 離脱中、自分が設定しているCPUモデルに代行プレイしてもらう

これにより、途中で離席する場合でも、試合を止めるか、CPUに任せて進行させるかを選べます。

### ホストを変更

ホストを変更する機能は、ルームを作成した本人が退出する場合などに、別の人間プレイヤーへホスト権限を譲渡するための機能です。

一時離脱中ではないアクティブな人間プレイヤーが選択肢に表示されます。  
他の人間プレイヤーが全員一時離脱中の場合は、ランダムな人間プレイヤーがホストになります。

その時点で自分以外に人間プレイヤーがいない場合は、ホスト権限を譲渡できないため、ルームは自動的に解散されます。

### 試合情報

試合情報タブでは、現在の試合の詳細情報を確認できます。

ホストであれば、試合形式の詳細変更も可能です。

---

## 途中参加とCPU代行

ルーム作成時に途中参加を許可している場合、人数が揃っていなくても試合を開始できます。  
その場合、足りないプレイヤー枠はCPUが代行プレイします。

また、試合中に人間プレイヤーが抜けて欠員が出た場合も、補充されるまでCPUが代行プレイします。

欠員が出たルームは、New Game内のルームリストに再表示され、他のプレイヤーが途中参加できるようになります。  
欠員がすでに補充されている間は、ルームリストには表示されません。

## 確認時のおすすめ手順

初めて確認する場合は、以下の流れがおすすめです。

1. PCブラウザでデモURLを開く
2. Home画面でManualを確認する
3. New Gameを開く
4. 「ルームを立ち上げる」を選択する
5. 1人 + CPUの構成でルームを作成する
6. CPU対戦で、山札・捨て札・役作り・効果カード・終局処理を確認する
7. オンライン対戦を確認する場合は、別ブラウザ、シークレットウィンドウ、または別端末から同じURLを開き、公開ルームへの参加を確認する
